# Telanico 3D Web

Public deployment repository for the Telanico 3D tabletop-map prototype.

This repository will contain **only the exported Godot web build** and deployment configuration. Original Blender models, source generator scripts, and the development project are maintained privately in `sgdenikin-sys/Telanico-3D-Lab`.

Website publishing is not configured yet. The next step is a browser-compatible Godot export and a GitHub Pages deployment workflow.
